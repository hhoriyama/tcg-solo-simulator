# TCG 一人回しシミュレーター

トレーディングカードゲームの「一人回し」——対戦相手を立てずに自分のデッキを回し、手札の噛み合いや展開を確認する練習——を、ブラウザ上で行うためのツールです。

`index.html` をダブルクリックして開くだけで動きます。ビルドもサーバーも不要で、外部ライブラリにも依存していません。盤面やデッキはブラウザの localStorage に保存され、右上の「保存データ書出」から JSON でバックアップできます。

**カードデータとカード画像は同梱していません。** カード名・効果テキスト・カード画像の著作権は各権利者に帰属するため、リポジトリには含めず、利用者が `fetch_cards.js` で各自取得する構成にしています。プレイシート画像も同様です。背景画像は `make_bg.py` を実行すれば生成できます。

初めて動かす場合は、カード管理画面の「サンプルカードを読み込む」を押すと、同梱の架空カード21枚で動作を確認できます。

## 技術構成

| 項目 | 内容 |
|---|---|
| 本体 | 単一の `index.html`（HTML + CSS + JavaScript、外部ライブラリなし） |
| データ保存 | ブラウザの localStorage（JSON でのエクスポート/インポートに対応） |
| カード取り込み | CSV / TSV をテキストエリアに貼り付け（スプレッドシートから直接コピペ可） |
| データ取得 | `fetch_cards.js`（Node.js、取得先URLを引数で指定して商品単位で取得） |
| 画像生成 | `make_bg.py`（Pillow + numpy でプロシージャル生成） |

---

## 使い方

### ① カード管理
CSV / TSV を貼り付けて「取り込む」。まずは **「サンプルカードを読み込む」** で動作確認できます。

列（1行目はヘッダー、カンマ or タブ区切り。スプレッドシートから直接コピペ可）

| 列 | 内容 | 例 |
|---|---|---|
| `no` | カードナンバー（一意キー。同じ no は上書き更新） | `SMP-1-001` |
| `name` | カード名 | `紅蓮の剣豪` |
| `title` | タイトル（作品名。デッキのプルダウンで使います） | `サンプルタイトル` |
| `color` | 赤 / 青 / 緑 / 黄 / 紫 | `赤` |
| `type` | キャラ / フィールド / イベント / AP | `キャラ` |
| `energyColor` | 必要エナジー（**その色を何個**） | `3` |
| `energyAny` | 無色ぶん（公式カードでは常に 0） | `0` |
| `ap` | 消費AP | `1` |
| `bp` | BP | `3500` |
| `gen` | 発生エナジー（エナジーラインで生む量。省略時 1、イベント/APは0） | `1` |
| `traits` | 特徴 | `サイヤ人` |
| `trigger` | カラー / ドロー / スペシャル / ファイナル / アクティブ / レイド / ゲット（無ければ空欄） | `スペシャル` |
| `text` | 効果テキスト（表示のみ。自動処理はしません） | `【登場時】カードを1枚引く。` |
| `image` | 画像パス（任意。空なら自動解決） | `images/SMP-1-001.png` |
| `rarity` | レアリティ（任意） | `SR` |
| `triggerText` | トリガー効果文（任意） | `カードを1枚引く。` |

- 公式の必要エナジーは「**指定色のエナジーをN個**」という表記なので、`energyColor` に数字を入れて `energyAny` は 0 のままにします。
- 値にカンマを含めたい場合は `"..."` で囲んでください。
- ヘッダーは日本語（`ナンバー` `カード名` `色` `種別` `必要エナジー` `消費AP` `発生エナジー` `特徴` `トリガー` `効果` など）でも認識します。

### 特定タイトルのカードをまとめて入れる（かんたん）

`get_cards.bat` を**ダブルクリック**するだけです（Windows。Mac/Linux は `sh get_cards.sh`）。
サンプルタイトルの全商品ぶん（パラレル除く 342枚）のカードデータと画像を取ってきて、

- `cards_sample.csv` … カードデータ
- `images/` … カード画像 342枚

を作ります。5〜10分ほどかかります。途中で閉じても、次に実行すれば続きから再開します。
※ Node.js（18以上）が必要です。入っていない場合はバッチが教えてくれます。

終わったら

1. `index.html` を開く
2. **① カード管理 →「CSVファイルを選ぶ…」→ `cards_sample.csv`**
3. **② デッキ構築 →「タイトル一覧(JSON)を読込」→ `titles.json`**
4. タイトルを選んで「新規」→ 右のカード一覧の `＋` でデッキを組む
5. **③ 一人回し** で回す

他のタイトルも同じやり方です。`get_cards.bat` をコピーして `--titlematch <英字タイトル>` の部分を変えるか、
`node fetch_cards.js --base <URL> --list-titles` でタイトル一覧を見て `--title "タイトル名"` を指定してください。

### カード画像

3通りあります。

**(A) `images` フォルダに置く（おすすめ）**

`index.html` と同じ場所に `images` フォルダを作り、**カードNoの `/` を `_` に置き換えた名前**で画像を入れます。

```
tcg-solo-simulator/
├─ index.html
├─ cards.csv
└─ images/
   ├─ SMP-1-001.png
   └─ SMP-1-002.png
```

CSV の `image` 列を書けばそのパスが優先されます（後述の `fetch_cards.js` は自動で書き込みます）。
フォルダ名・拡張子は ①カード管理 の「カード画像」欄で変更できます。カードの表示サイズもそこのスライダーで変えられます。

**(B) 公式サイトから直接表示する（ダウンロード不要）**

① カード管理 の「**画像が無いカードは公式サイトから表示**」にチェックを入れると、
ローカルに画像が無いカードだけ公式サイトの画像を読み込みます。すぐ試したいときに便利です（インターネット接続が必要）。

**カード裏・プレイシート**

① カード管理 の「カード画像」欄で、3つのファイル名を指定できます（既定値は下記。`index.html` と同じ場所に置いてください）。

| 設定 | 既定 | 使われる場所 |
|---|---|---|
| カード裏 | `img_card_jp.png` | 山札・ライフの束、裏向きマーカー |
| APカード裏 | `img_apcard_jp.png` | APエリアの「まだ使えないAPカード」 |
| プレイシート | `playsheet_wide.png` | シアターモードの盤面 |
| シートの外の背景 | `bg_theater.png` | シアターモードで盤面の周りに敷く背景 |

読み込めたかどうかは欄の右に `カード裏✓ APカード裏✓ プレイシート✓` と出ます。
プレイシートがPDFの場合は、画像に変換してから置いてください（例：`pdftoppm -png -r 150 -singlefile playsheet.pdf playsheet`）。

シート画像が 16:9 でないと画面の左右に余白が出るので、元のシート（`playsheet.png`）を中央に置いて
**左右に赤地＋白い結晶模様を描き足した** `playsheet_wide.png`（3118×1754）を同梱しています。
盤面の外側には、同じ色味で作った `bg_theater.png`（2560×1440）を画面いっぱいに敷きます。
どちらも同梱の `make_bg.py` で作っています（要 Pillow / numpy）：

```
pip install pillow numpy
python make_bg.py
```

色や模様を変えたいときは `make_bg.py` の `c_in` / `c_out`（赤のグラデーション）と
`n_big` / `n_small`（白い結晶の数）をいじってください。
別の絵を使いたい場合は、① カード管理 の「プレイシート」「シートの外の背景」に
ファイル名を入れれば差し替えられます。

**(C) 別の場所にある画像を取り込む**

①カード管理 →「画像フォルダを取り込む」でフォルダを選ぶと、ブラウザ内（IndexedDB）に保存されます。
ファイル名（拡張子を除く）がカードNoの `/` を `_` にしたものと一致する画像が使われます。この方法なら `images` フォルダを置かなくても表示できます。

### ② デッキ構築

画面は **左＝選択中カードの詳細／中央＝メインデッキ／右＝カード一覧** の3列です。カードは**画像で並びます**。

**タイトルで分ける**

上部の **タイトル** プルダウンでタイトル（作品）を選ぶと、その**タイトルのデッキだけ**がデッキのプルダウンに出て、**カード一覧もそのタイトルのカードだけ**になります。
デッキは作成時にタイトルが決まり、別タイトルのカードは入れられません。

タイトルの一覧は公式サイトから取得したものを使います（`titles.json`）。

- **`get_titles.bat` をダブルクリック**すると `titles.json` を作成・更新できます（数秒。画像は落としません。Mac/Linux は `sh get_titles.sh`）
- `get_cards.bat` などでカードを取得したときにも `titles.json` は自動で作られます
- **「タイトル一覧(JSON)を読込」** ボタンで読み込むと、**公式の全タイトルが公式の並び順で**プルダウンに出ます。カードを持っていないタイトルは「（カード未取込）」、持っているタイトルは「（N枚）」と枚数が付きます
- 読み込まなくても、取り込んだカードの `title` 列からタイトルは自動で作られます（その場合は持っているタイトルだけが出ます）
- 新しいタイトルが追加されたら `get_titles.bat` を実行し直してください

**メインデッキの表示**

ラジオボタンで2種類を切り替えられます。

- **種類ごと** … 同じカードは1枚にまとめ、右上のバッジと `− 枚数 ＋` で増減します
- **1枚ずつ** … 4枚積んでいれば4枚並べます。デッキ全体を1枚ずつ眺めたいとき用（各カードの `−` で1枚減らせます）

**トリガーの内訳**

APカードの下に、メインデッキの**トリガー種類別の枚数と比率**が出ます。
**ゲット / ドロー / アクティブ / レイド / カラー / ファイナル / スペシャル** の7種類＋「トリガーなし」を、棒グラフ付きで表示します。比率はメインデッキの現在の枚数に対する割合です。

**必要エナジーの分布**

その下に、メインデッキの**必要エナジーごとの枚数と比率**が 0 / 1 / 2 / … の順で並びます（最低でも 0〜5 は常に表示）。見出しに**平均必要エナジー**も出るので、重さの調整に使えます。

**カードの操作**

- カード**画像をクリック** → 左に大きく表示され、カード名・No・必要エナジー・BP・特徴・効果・トリガーが出ます
- 画像の下の **`−` / `＋`** で枚数を増減します。右上のバッジが現在の枚数です
- サイズのスライダーでカードの大きさを変えられます
- 右のカード一覧は 検索 / 色 / 種別 で絞り込めます
- 上部の **「カード一覧を隠す」** で右カラムを畳めます。畳むと**左＝詳細／中央＝メインデッキ（広め）／右＝トリガー内訳と必要エナジーの分布**という並びになり、組み上がったデッキと統計を並べて見られます（設定は保存されます）
- 下の入力欄に `SMP-1-001 x4` のように貼って「このデッキに反映」でも一括登録できます

チェック内容：メイン50枚 / AP3枚 / 同名（同no）4枚まで / 制限トリガー（スペシャル・カラー・ファイナル）各4枚まで。
※ 枚数が揃っていなくても一人回しは開始できます（警告表示のみ）。

### ③ 一人回し
デッキと先攻/後攻を選んで「開始」。

画面は **左＝選択中カードの拡大表示／中央＝盤面／右＝操作パネル** の3列です。

- 手札7枚 → 必要ならマリガン（1回）→ ライフ7枚セット、の順で進みます
- **手札は自動で並び替わります**：左から **キャラ → フィールド → イベント** の順、それぞれ**必要エナジーの少ない順**（同じなら消費AP、カードNoの順）。ドローや手札に戻したあとも自動で並び直ります
- 盤面のカードを**クリック**すると、**左に大きく表示**され、カードの横に移動先メニューがポップアップします（同じボタンは右パネルにも出ます）。Esc か外側クリックでポップアップは閉じますが、左の拡大表示は残ります
- **フロントライン／エナジーライン**には4枚ぶんの枠が常に表示されます
盤面の並びはこうなっています。

```
[ ライフ  ｜ フロントライン ｜ 山札   ]
[ リムーブ ｜ エナジーライン ｜ 場外   ]
[ 手札                              ]
[ APエリア ｜ 解決エリア             ]
```

- **フロントライン／エナジーライン**は4枚ぶんの枠（縦向き）が常に表示されます
  - **縦向き＝アクティブ／横向き＝レスト**です
  - カードを置いた直後は**レスト（横向き）**になります
  - **ターン開始時（スタートフェイズ）に、この2つのラインのカードは全部アクティブ（縦向き）に戻ります**（エンドフェイズでも戻ります）
- **ライフ**はカードが7枚重なった見た目で、減ると重なりも減ります
- **場外・リムーブ**は**クリックすると中身が全部**表示され、そこから1枚ずつ行き先を選べます（**エナジーライン／フロントラインへ**も直接置けます）
- どの山も**ドラッグ＆ドロップで直接カードを置けます**（ライフは下に入ります）
- 各山の右下に枚数バッジが出ます。**山札**をクリックすると中身を検索できます（閉じるときにシャッフル）
- **APエリア**は最初から3枠並びます。そのターンまだ使えないAPカードは**白いカード裏**で表示され、使えるAPカードは**クリックするたびに縦↔横（アクティブ↔レスト）**が切り替わります（APカードにはポップアップは出ません）
- カードは**ドラッグ＆ドロップ**でも動かせます。ドラッグ中は置けるエリアが点線で光り、画面下に「山札の上 / 山札の下 / ライフの上 / ライフの下 / 場外 / リムーブ」のドロップ先バーが出ます
  - 手札からエナジーライン／フロントラインにドロップした場合はコスト（エナジー・AP）をチェックして登場扱いになります。自由操作モードならコストを無視してそのまま置けます
- 「次のフェイズへ」で スタート → 移動 → メイン → アタック → エンド → 次ターン と進みます
- **自由操作モード** をONにすると、フェイズ制限とコストチェックを無視してカードを自由に動かせます（効果の解決を手で再現するとき用）
- 相手の盤面はありません。アタックすると「ブロックされない（ダメージN）／ブロックされた（相手BPを入力してバトル判定）／宣言だけ」から選びます
- 相手ライフは右パネルのカウンタで管理します（± ボタンで手動調整も可）
- 「自分がダメージ1」でライフをめくり、トリガー種別を確認できます
- 「元に戻す」で直前の操作を取り消せます
- 用語は公式表記に合わせて **場外**（旧サイドライン）・**リムーブ**（旧除外）にしています

#### レイドとマーカー

**フロントライン／エナジーラインにあるカードの上に、別のカードをドラッグ＆ドロップ**すると、重ね方を選べます。

| 選択肢 | 内容 |
|---|---|
| **レイドする（重ねる）** | 対象のキャラにレイドカードを重ねます（上のカードのステータスを参照。手札からのときはコストも支払います） |
| **カードの下に表向きでマーカーにする** | 対象カードの下に、表向きのマーカーとして置きます |
| **カードの上に裏向きでマーカーにする** | 対象カードの上に、裏向きのマーカーとして置きます |
| **このラインにそのまま置く** | 重ねずに、そのラインの空きスロットに置きます |

**重なりの見え方**

- **レイド**：一番上のカードが枠にぴったり収まり、**下になっているカードが少し左上にずれて**顔を出します。何が下にあるか見たままで分かります
- **表向きマーカー（下）**：同じように、さらに左上にずれて重なります
- **裏向きマーカー（上）**：**横向きのカード裏**として、左上にずらして**カードの下（奥）**に重なります
- ずらし量はカードの大きさに比例するので、シアターモードで大きくしても同じ見え方になります
- 重なりが4枚以上／裏マーカーが3枚以上のときは、いちばん奥に `+N` と出ます
- そのカードをクリック →「**マーカーを見る**」で中身を確認でき、1枚ずつ好きなエリア（手札・場外・リムーブ・山札・ライン）へ取り出せます
- マーカー付きのカードがラインから離れると、マーカーも一緒に**場外**へ行きます

#### 録画とリプレイ

**一人回しの操作は自動で録画されます。** ゲームを開始すると右パネルに「録画中 N手」と出ます。
録画は「盤面が変化するたび」に1手ぶんの盤面まるごとを記録する方式なので、途中の状態にいつでも飛べます。

**再生のしかた**

- 一人回し画面の **「別タブで再生」** … 新しいブラウザタブが開き、そこで再生されます。**元のタブはそのまま操作を続けられます**（録画も続きます）
- **④ リプレイ** タブ … 保存された録画の一覧。各行から「別タブで再生」「このタブで再生」「書き出し」「削除」ができます

**再生画面の操作**

`⏮ 先頭` / `◀ 1手戻る` / `▶ 再生・⏸ 停止` / `▶ 1手進む` / `⏭ 最後` とスライダー、速度（遅い・標準・速い・最速）。
再生中の盤面は**読み取り専用**で、カードをクリックすると左に拡大表示だけされます（移動メニューやドラッグは無効）。

**キーボード操作**（再生中のみ有効。画面にも一覧を出しています）

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止 |
| `←` `→` | 1手ずつ 戻る / 進む |
| `Shift` + `←` `→` | 10手ずつ |
| `Home` `End` | 先頭 / 最後へ |
| `↑` `↓` | 速度を上げる / 下げる |
| `T` | シアターモード 切替 |
| `F` | 全画面 切替 |
| `+` `-` | カードの大きさ（シアター中） |
| `C` | 枠に合わせる（位置合わせモード） |
| `H` | 手札の表示 / 非表示 |
| `Esc` | 停止 / シアター終了 |

入力欄にカーソルがあるときはキー操作を横取りしません。

**シアターモード（UIを消して盤面だけ）**

動画撮影用に、**枠とカード画像だけ**を表示するモードです。再生中に **`T`** キー、または再生パネルの「シアターモード（UIを消す）」で入ります。

- ヘッダー・タブ・左の詳細パネル・右の操作パネル・エリア名・枚数バッジ・解決エリアの操作ボタンまで、**画面上の文字とUIを全部消します**
- 残るのは各エリアの枠とカードだけ。カード画像があるカードは、BPやコストの数字も出しません
- 画像があるカードは、左端の色帯（赤・青などの色表示）も出しません。これは一人回しの画面でも同じです
- カードは自動で大きくなります（既定130px）。`+` `-` で大きさを変えられます
- **背景にプレイシート**、山札・ライフ・裏向きマーカーには**公式のカード裏**、APカードには**APカード裏**が使われます
- **`F`** で全画面。マウスを動かしたときだけ小さな操作バーが下に出て、2.5秒動かさないと**バーもマウスカーソルも消えます**（録画に写り込みません）
- 再生・コマ送りのキー操作はシアター中もそのまま使えます。**`T`** か **`Esc`** で元に戻ります
- 手札と解決エリアは、シートの下の専用フレームに分けて表示します（**`H`** で消せます）
- 盤面の左右にできる余白は、プレイシート画像を引き伸ばして暗くしたもので埋めています

**プレイシートの枠に合わせる**

プレイシート画像が読み込めているときは、シアターモードの盤面が**シートに印刷されている枠の上に重なるように**配置されます。

| エリア | 合わせ先 |
|---|---|
| フロントライン / エナジーライン | 印刷された4つのカード枠 |
| APエリア | 印刷された3つのカード枠 |
| ライフ | 左の LIFE AREA の列。**横向き（カードの上が左）**にして7枚を上から下へずらして重ねます。列が細いので左側は切れます |
| 山札 / リムーブ / 場外 | DECK / REMOVE AREA / OUTSIDE AREA の枠の中心。**一番上のカードの位置は枚数が変わっても動きません**（下のカードが左上に伸びます） |

ライフの段の間隔は7枚ぶんで固定なので、ライフが減っても残りのカードは動きません。

**カードの大きさは全エリア共通**で、フロントライン／エナジーラインの枠に合わせた大きさになります
（ライフ・山札・場外・リムーブ・手札・解決エリアも同じ大きさ）。
シートに印刷された山札・ライフなどの枠はカード1枚より細いので、カードは枠からはみ出します。

**手札と解決エリア**はシートの外に出して、盤面の**下の専用フレーム**に「手札」「解決エリア」と
見出し付きで並べます（幅はおよそ 6:4）。カードが入りきらないときは少しずつ重ねて収めます。
フレームのぶん盤面は少し小さくなります。**`H`**（操作バーの「手札」）でフレームごと消すと、
盤面が画面いっぱいまで広がります。

既定の座標は同梱のプレイシート画像を実測した値です。別のシートを使うときや、
ずれが気になるときは **`C`**（操作バーの「位置合わせ」）で調整できます。

| キー | 動作 |
|---|---|
| `Tab` / `Shift`+`Tab` | 調整するエリアを切り替え |
| `←` `↑` `↓` `→` | 位置を動かす（0.2%ずつ） |
| `Shift` + 矢印 | 枠の大きさを変える（フロントの枠を変えると全カードの大きさが変わります） |
| `Alt` + 矢印 | 0.05%ずつ細かく |
| `R` | そのエリアだけ初期値に戻す |
| `C` / `Esc` | 位置合わせを終了 |

調整した値はブラウザに保存されるので、次に開いたときもそのままです。

**保存と受け渡し**

- 録画はブラウザ内（IndexedDB）に自動保存され、④ リプレイ タブに溜まります
- **「録画を書き出し」** で JSON ファイルとして保存できます。カードの情報も一緒に入るので、**別のPCでもそのまま再生できます**
- ④ リプレイ タブの **「録画ファイル(JSON)を読み込む」** で読み込みます

#### 解決エリア（効果の処理用）

盤面いちばん下、APエリアの右にあります。

「山札の上から3枚見て、1枚を手札に加え、残りを山札の下に置く」のような効果を手で処理するための一時置き場です。

- **山札の上から [N] 枚 → 見る**：山札の上からN枚を解決エリアに表向きで並べます
- **ライフの上から**：ライフの上からN枚を解決エリアへ（ライフを見る効果用）
- **山札を全部見る**：山札の中身を一覧表示。検索でき、クリックしたカードが解決エリアに移ります。閉じるときに山札をシャッフルできます
- **山札をシャッフル**：いつでも実行できます

解決エリアのカードをクリックすると、行き先を1枚ずつ選べます（手札 / 山札の上 / 山札の下 / ライフの上 / ライフの下 / 場外 / リムーブ / フロントライン / エナジーライン）。
**◀ 左へ / 右へ ▶** で並び順を変えられるので、「好きな順番で山札の下に置く」も再現できます。

残ったカードは下の「残り全部を：」ボタンで、**左から順に**まとめて戻せます。
（例：山札の上から3枚 → 1枚をクリックして「手札に戻す」→「残り全部を 山札の下へ」）

盤面や手札のカードからも「解決エリアへ」で移動できるので、一時的に脇に置きたいときにも使えます。

## カードリストからデータを取得する（fetch_cards.js）

公式カードリストは普通のHTMLで返ってくるので、取得できます。付属の `fetch_cards.js` は
**カードのCSVと画像をまとめて落として、そのまま取り込める形**にしてくれます。Node.js 18以上があれば追加パッケージは不要です。

```bash
# 1) 収録商品の一覧を見る
node fetch_cards.js --base <URL> --list
node fetch_cards.js --base <URL> --list --title <作品名>

# 2) 商品IDを指定して取得（CSV + 画像）
node fetch_cards.js --base <URL> --series 570101 --out cards_UA01BT.csv

# タイトル丸ごと
node fetch_cards.js --base <URL> --title <作品名> --out cards_jjk.csv

# 画像はいらない
node fetch_cards.js --base <URL> --series 570101 --no-images

# パラレル（_p1 など）も含める（既定は除外）
node fetch_cards.js --base <URL> --series 570101 --parallel
```

| オプション | 意味 | 既定 |
|---|---|---|
| `--out <file>` | 出力CSV | `cards.csv` |
| `--images <dir>` | 画像の保存先 | `images` |
| `--wait <ms>` | リクエスト間隔 | `250` |
| `--append` | 既存CSVに追記 | off |
| `--titlematch <英字>` | タイトルを英字の部分一致で指定（例 `--titlematch <英字タイトル>`） | - |
| `--list-titles` | タイトル一覧を表示 | - |
| `--dump-titles [file]` | タイトル一覧をJSONで出力（既定 `titles.json`。通常の取得でも自動生成） | - |

取得できる項目：カードNo / 名前 / **タイトル** / 色 / 種別 / 必要エナジー / 消費AP / BP / 発生エナジー / 特徴 / 効果 / トリガー種別 / トリガー効果 / レアリティ / 画像。
既にある画像はスキップするので、途中で止めても再実行すれば続きから進みます。

取得したら `cards_UA01BT.csv` をテキストエディタで開いて中身をコピー → ①カード管理 に貼り付けて「取り込む」。

> 個人利用の範囲でお使いください。連続アクセスにならないよう既定で 250ms 間隔を空けています。

## 実装しているルール

- 山札50枚、APカード3枚
- ライフ7枚、0枚で敗北 / スタートフェイズにドローできず（山札0枚）でも敗北扱いのログ
- **APカードの枚数**：先攻 1 → 2 → 3 → 3…／後攻 2 → 2 → 3 → 3…
- **ドロー**：先攻1ターン目のみドローなし
- **エナジー**：エナジーラインのカードの発生エナジー合計を参照する「しきい値」方式（エナジーは消費されません）。必要エナジーは公式表記どおり「**その色のエナジーがN個以上**」で判定します
- **AP**：APカードをレストにして支払う。エンドフェイズ／スタートフェイズでアクティブに戻ります
- **登場したカードはレストで置かれ**、次のスタートフェイズ（およびエンドフェイズ）でアクティブになります。挙動を変えたい場合は `index.html` の `beginTurn()` と登場処理の `inst.state='rest'` を書き換えてください
- フロントライン最大4／エナジーライン最大4
- キャラは原則エナジーラインに登場 → 移動フェイズでフロントラインへ
- アタック：アクティブなフロントラインのキャラをレストにして宣言 → ブロックされなければライフ1枚（効果テキストに「ダメージ2」を含む場合は2枚）
- バトル：BP比較、同値は**アタック側の勝ち**
- エンドフェイズ：レストのカードをアクティブに戻す／手札は8枚まで（超過は警告表示、手札をクリックして「場外へ」）
- レイド：手札のカードを盤面のキャラに重ねます（上のカードのステータスを参照）
- エリア：山札 / ライフ / 場外 / リムーブ / フロントライン / エナジーライン / APエリア / 解決エリア（このツール独自の作業用）
- エクストラドロー：AP1でターン1回
